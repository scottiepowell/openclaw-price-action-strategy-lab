# No Trade Filters

## Purpose

Identify situations where a candidate should be ignored even if a surface-level setup appears valid.

## Common filters

- target already hit
- higher-timeframe obstacle present
- invalidation already consumed
- room-to-target is insufficient
- context is incomplete
- evidence is contradictory
- the move is only a hindsight breakout

## Rule

If a no-trade filter is active, the candidate stays out.

## Documentation note

Filters should be written so they can be checked from the recorded evidence, not inferred later.
