# Promotion Checklist

## Purpose

Check whether a candidate is ready to move forward from refinement into paper validation.

## Checklist

- [ ] candidate definition is explicit
- [ ] target relationship is documented
- [ ] invalidation is documented
- [ ] no-trade filters are documented
- [ ] replay evidence supports the candidate
- [ ] contradiction cases have been reviewed
- [ ] paper-only language is used throughout
- [ ] no live-trading assumptions are present
- [ ] candidate promotion criteria are satisfied

## Promotion note

See `candidate_promotion_criteria.md` for the full gate.

If any box cannot be checked confidently, stop and gather more evidence.
