# Validation Checklist

- [ ] Source references exist
- [ ] Replay case is linked to evidence
- [ ] Data quality gates are checked
- [ ] Labels are conservative and specific
- [ ] Contradiction evidence is documented
- [ ] No trade signal is implied

## Before marking a case complete

- [ ] The case can be traced back to a source manifest
- [ ] The time window is clear
- [ ] The candidate terms are defined in the knowledge base
- [ ] The label does not overstate certainty
- [ ] The notes explain why the case matters

## Red flags

- speculative language
- missing evidence link
- implied profitability claim
- live-trading wording
- contradictory labels without a resolution note
