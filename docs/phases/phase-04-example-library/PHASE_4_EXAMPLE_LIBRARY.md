# Phase 4 Example Library

## Purpose

Capture concrete transcript, snapshot-map, and JPEG-backed examples that support or weaken the Phase 3 rule candidates.

## Repo alignment

- source evidence indexes: `evidence/google_drive_refs/`
- candidate indexes: `knowledge_base/rule_candidates/`
- example cards: `docs/phases/phase-04-example-library/example-cards/`
- canonical example knowledge base: `knowledge_base/examples/`

## What counts as an example

An example is a structured evidence record showing how a concept appears in the course material.

Examples may support:
- current range
- support / resistance
- target behavior
- 78 decision levels
- same-candle ranges
- tighter range refinement
- no-fib / candle-derived levels
- entry-readiness blockers

## What examples are not

- not final rules
- not trade instructions
- not execution logic
- not a profitability claim

- EX-001 — Current Range

## Example library purpose

The library should help answer:
- which examples strongly support a candidate
- which examples show ambiguity
- which examples suggest a candidate should be split
- which examples should become replay cases later
