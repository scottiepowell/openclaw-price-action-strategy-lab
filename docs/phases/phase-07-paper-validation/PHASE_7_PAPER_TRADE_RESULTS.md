# Phase 7 Paper Trade Results

## Purpose

Record the observed results of paper-only candidate validation.

## Recommended structure

- candidate tested
- date/time window
- expected context
- observed context
- result summary
- invalidation notes
- follow-up action

## Result categories

- keep
- keep but refine
- split
- downgrade
- reject
- needs more evidence

## Reporting rules

- report what happened, not what was hoped for
- avoid performance claims unless separately validated
- keep any execution-language clearly paper-only
- note whether the candidate behaved structurally as expected
