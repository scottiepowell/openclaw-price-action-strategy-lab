# Phase 1.1 Glossary Refinement

## Purpose

Tighten the core glossary into working repo language for replay, candidate indexing, and paper-readiness planning.

## Refined terms

### Current Range
The active structure price is operating inside now. Use it to anchor support, resistance, target, and invalidation context.

### Support
A defended lower price area. If support is unclear, the setup stays weak.

### Resistance
A defended upper price area. If resistance is unclear, the setup stays weak.

### Target
The next meaningful destination price is expected to reach. A candidate should name a target before it is considered further.

### Invalidation
The condition or level that proves the candidate wrong. If invalidation is missing, do not promote the setup.

### Room to Target
The remaining distance between the candidate and the target. If room is too small, treat it as a no-trade.

### No-Trade Filter
A blocker that stops a weak or overfit setup from becoming a candidate.

### Candidate
A supported setup concept under review. A candidate is still analysis, not instruction.

### Replay Case
A historical evidence record used to test, label, or challenge a candidate.

### Contradiction Case
A replay record showing why a candidate is weak, narrower than expected, or invalid.

### Paper-Validation Candidate
A candidate that has survived conservative review well enough to be considered for paper-only validation later.

## Use rules

- Keep every definition evidence-bound.
- Do not turn glossary terms into trade instructions.
- Do not treat a level break as an entry.
- Prefer conservative wording when evidence is incomplete.
