# Phase 6 Paper Trade Readiness Gates

## Purpose

Define the minimum evidence required before a candidate may move into paper-only validation.

## Gate categories

- evidence completeness
- label clarity
- contradiction coverage
- no-trade filters
- target/invalidation definition
- paper-only operational safety

## Minimum gate set

- source reference exists
- replay examples support the candidate
- contradiction cases have been reviewed
- no-trade filters are explicit
- the candidate cannot be mistaken for a live-trading rule

## Promotion rule

A candidate may move forward only when the documentation shows:

- a stable definition
- a clear target relationship
- a defined invalidation path
- enough context to avoid hindsight-only interpretation
- the Phase 6 candidate promotion criteria are satisfied

## Fail fast conditions

- ambiguous language
- missing evidence links
- profitability claims
- live-order wording
- unsupported assumptions about execution
