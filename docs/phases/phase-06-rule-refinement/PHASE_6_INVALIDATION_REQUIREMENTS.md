# Phase 6 Invalidation Requirements

## Purpose

Define what must invalidate a candidate.

## Requirements

- invalidation must be explicit
- invalidation must be testable against the evidence
- invalidation must be tied to a recorded level, break, or context change
- invalidation must not rely on vague interpretation

## Common invalidators

- opposite structural break
- failed follow-through
- target already reached before the setup completes
- higher-timeframe conflict
- no-trade filter triggered
