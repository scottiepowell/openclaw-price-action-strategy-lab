# Phase 6 Rule Refinement

## Purpose

Refine surviving rule candidates into conservative paper-trade candidate definitions.

## Inputs

- replay cases
- contradiction cases
- evidence crosswalks
- validation matrix notes
- candidate split proposals

## Outputs

- refined candidate definitions
- explicit no-trade filters
- readiness-gate criteria
- promotion or rejection notes
- candidate promotion criteria document
- required evidence definition
- contradiction search definition
- invalidation requirements
- target requirements
- room-to-target requirements
- timeframe alignment requirements
- support/resistance context requirements

## Refinement rules

- tighten language before broadening scope
- split a candidate when two behaviors are being mixed
- reject a candidate if the evidence only supports hindsight interpretation
- keep invalidation explicit and testable
- never convert a level break into a standalone signal

## Review questions

- What exact context must exist before the candidate is considered?
- What must be true for the target to count?
- What conditions invalidate the setup?
- What contradiction cases still need to be collected?

## Exit criteria

- candidate definition is conservative
- target and invalidation are explicit
- no-trade filters are documented
- evidence traceability is preserved
