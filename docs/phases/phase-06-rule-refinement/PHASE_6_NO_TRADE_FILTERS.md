# Phase 6 No-Trade Filters

## Purpose

Define the filters that block a candidate even when the surface setup looks valid.

## Core filters

- target already hit
- higher-timeframe obstacle present
- invalidation already consumed
- room-to-target is insufficient
- context is incomplete
- evidence is contradictory
- the move is only a hindsight breakout

## Rule

If a no-trade filter is active, the candidate stays out.

## Documentation rule

Each filter must be checkable from recorded evidence.
