# Phase 6 Required Evidence

## Purpose

Define the minimum evidence set a refined candidate must have before paper validation.

## Required evidence

- source reference or crosswalk exists
- replay examples support the candidate
- contradiction cases have been reviewed
- target relationship is explicit
- invalidation path is explicit
- no-trade filters are explicit
- room-to-target or equivalent entry filter is documented where relevant
- language remains paper-only

## Evidence quality rules

- evidence must be traceable from the candidate record
- evidence must not depend on hindsight-only interpretation
- evidence must be strong enough to explain why the candidate survives review
- evidence gaps must be called out instead of implied

## Fail fast conditions

- missing source references
- missing replay support
- missing contradiction review
- unsupported assumptions
- live-trading wording
